# 📔 Jisho: VS Code 用オフライン日本語辞書

サイドバーで使えるオフラインの日本語辞書です。エディタから離れることなく、
単語を調べ、漢字を読み、活用を確認できます。

## Jisho とは

Jisho は、あなたのマシン上だけで動作する和英辞典です。読むために作られています。
日本語を含むファイルを開いていて、知らない単語に出会ったとき、ブラウザを開かずに
その答えが欲しい、という場面のためのものです。

すべての検索はローカルのデータベースに対して実行されます。ネットワーク通信も、
アカウントも、レート制限もありません。macOS および iOS の辞書アプリ
Shirabe Jisho を手本にしています。

この辞書には約 218,000 語と 10,000 字の漢字が収録されており、JMdict と KANJIDIC を
出典としています。これらは公開されている日本語辞書の多くが基にしているデータです。
完全な一覧は「データの出典」を参照してください。

## インストール

VS Code の拡張機能ビュー、またはマーケットプレイスから
**Jisho: Offline Japanese Dictionary** をインストールしてください。

> [!Note]
>
> Jisho には **VS Code 1.123 以降** が必要です。

パネルを初めて開いたとき、Jisho は辞書をダウンロードします。約 125 MB で、
ディスク上では約 450 MB に展開され、進捗は通知に表示されます。これは一度だけです。
それ以降はすべてローカルで完結します。

## 検索

検索欄は四種類の入力を受け付けます。どれを使っているかを伝える必要はありません。

| 入力する内容 | 例           | 得られるもの           |
| ------------ | ------------ | ---------------------- |
| 日本語       | `図書館`     | その単語そのもの       |
| かな         | `としょかん` | その読みを持つ単語     |
| ヘボン式     | `toshokan`   | 同じものを字訳したもの |
| 英語         | `library`    | その意味を持つ単語     |

結果は関連度順に並ぶので、探していた単語がまず先頭に来ます。
